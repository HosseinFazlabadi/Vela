# Roadmap

This is a direction for ongoing development, not a release-date commitment.

- Broader real-device validation for capture, discs and renderers.
- Developer ID signing and notarized public packages.
- Larger extension compatibility corpus and reproducible service fixtures.
- Better library organization and playlist interoperability.
- Stronger isolation for native operations invoked by extensions.
- Reproducible release builds with pinned dependency sources and automated integration reporting.

Discuss proposals before large changes. Priorities follow reproducible issues and contributor capacity.
