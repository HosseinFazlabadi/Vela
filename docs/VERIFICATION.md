# Verification

The 1.1 engine has a software suite of 117 checks, including eight playback formats, track/subtitle/chapter controls, generated disc input, capture, export, network receiving, native extension contracts, engine rebinding and cancellation. Two pinned third-party scripts and optional VLSub dialog activation extend the local corpus.

Capture fixtures include a stereo test signal, static video and a complete receiving-client media segment. Export files are decoded independently; signal presence and A/V start times are checked. Release packages are extracted, signature-checked and exercised again before distribution.

The suite uses separate user data and extension home/config paths. Hardware access is not required. Hardware, remote subtitle services, all possible inputs and every third-party script are outside the stated certification. CI performs repository/syntax checks, not the full media/device suite.

Public packaging replaces reference artwork with system symbols and an original logo. Results and checksums attached to a release identify the actual tested artifact. Never infer bug-free status or universal compatibility from a finite test count.
