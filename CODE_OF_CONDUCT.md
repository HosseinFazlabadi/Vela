# Community standards

Treat contributors and users with respect. Critique code and ideas constructively. Harassment, threats, discrimination, sharing private information, spam and abusive conduct are not acceptable.

Keep issues and discussions relevant, describe problems clearly and assume good intent. Maintainers may edit or remove inappropriate content and restrict participation when needed to protect the community.

Report conduct concerns privately through an appropriate GitHub reporting channel. These standards apply in the project's issues, pull requests and discussions.
