# Changelog

## 1.1 — First public release

- Native macOS playback with the bundled VLC 3.0.24 ARM64 engine.
- Independent media library, queues, saved playlists, bookmarks and playback controls.
- Capture with optional system audio, continuous static-screen frames and live output switching.
- Conversion, recording and network streaming with software verification fixtures.
- Native Lua extension dialogs, pinned API bindings and compatible compiled modules/packages.
- Managed shell-command cancellation, wider extension layouts and additional real-extension compatibility checks.
- Public-distribution artwork, installation documentation and contributor/release workflows.

Build 4 is the public packaging revision. Earlier local builds were not public GitHub releases.
